# Assistant for Fate

A free, open-source digital character sheet, dice roller and module system for the Fate Core
roleplaying game system. Built with Vue 3, Ionic and Capacitor for iOS, Android and the web.

- Google Play: https://play.google.com/store/apps/details?id=com.sonder.fate_core&pli=1
- Web version: https://fate.stanislavsonder.com
